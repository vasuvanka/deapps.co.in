## 🎨 Design System: Obsidian Champagne

Engineered natively for OLED dark mode environments to maintain battery efficiency, high contrast, and visual restfulness.

- **Surface Base**: `#0D0D11`
- **Surface Raised**: `#14141A`
- **Surface Elevated**: `#1A1A22`
- **Surface Border**: `#23222B`
- **Champagne Light (Focus)**: `#E2C392`
- **Champagne Base (Accent)**: `#C9A974`
- **Champagne Container**: `#2A241A`
- **Curated Themes**: *Obsidian Champagne*, *Deep Ember*, *Forest Fog*, *Minimal Noir*

## 🔒 The deApps Standard

1. **0 Bytes Telemetry**: Zero analytics SDKs, zero user tracking, zero remote telemetry.
2. **100% On-Device**: Local-first SQLite & Preferences. Your data never touches a server.
3. **Zero Advertising**: No banners, no interstitial ads, no subscription traps.
4. **Sub-millisecond Tactile Response**: Built for rapid one-handed reach with zero cognitive friction.

npm run build

# Preview production build
npm run preview
